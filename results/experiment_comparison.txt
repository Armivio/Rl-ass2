========================================================================
ANALYSIS
========================================================================

Experiment 1 (baseline for this comparison):
  Progress shaping alone. The agent receives a bonus proportional
  to Manhattan-distance reduction each step. This guides exploration
  toward the target without revealing its location in the state.

Experiment 2 (adds obstacle-proximity penalty w=0.1):
  On top of Exp 1, a small penalty fires when the nearest ray
  reading is below 0.15 (i.e. the agent is within ~15% of the
  max ray length from a wall or obstacle). The penalty scales
  linearly: 0 at threshold, -0.1 at the wall face.

Per-grid success-rate delta (Exp2 - Exp1):
  small_grid      : ++0.000
  A1_grid         : -0.057
  large_grid      : -0.063

Interpretation:
  A positive delta means the proximity penalty helped; the agent
  learned to stay away from walls, reducing wasted collision steps
  and improving path efficiency. A negative delta means the extra
  penalty introduced conflicting gradient signal that destabilised
  learning for this grid/episode budget -- the agent learned to
  avoid obstacles but at the cost of reduced goal-seeking behaviour.

Note: all runs use frame_stack=1 + explicit orientation feature
(8 ray distances + 2D heading vector = 10-dim observation),
auto-computed eps_decay = 0.7 x episodes x max_steps = 84,000 steps,
curriculum start radius 4, eval starts >= 60% max Manhattan distance.
